# Amplifiers Overview

This category contains specifications and reference documentation for professional power amplifiers and loudspeaker processing amps.

## Information Stored Here
- **Power Ratings**: Output wattage at 2 Ω, 4 Ω, 8 Ω, and 70V/100V distributed lines
- **Topology & Channels**: Class D, Class TD, multi-channel configurations (2-ch, 4-ch, 8-ch)
- **Integrated DSP**: Crossover filters, parametric EQ, FIR filtering, peak/RMS limiters, speaker presets
- **Monitoring & Network Control**: Ethernet monitoring, Dante inputs, GPIO, fault detection
