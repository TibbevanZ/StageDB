# Line Arrays Overview

This category contains specifications and reference documentation for line array elements and touring sound reinforcement modules.

## Information Stored Here
- **Module Architecture**: 2-way, 3-way, active/passive modular line array elements
- **Acoustic Dispersion**: Horizontal directivity (e.g. 80°, 100°, 120°) and inter-cabinet vertical splay range
- **Driver Configuration**: Dual/quad LF woofers, planar wave guides, compression drivers
- **Rigging & Safety**: Splay pin angles, maximum suspended box count, load ratings, pullback frames
- **Frequency Response & Output**: Full-range coverage specs, max SPL output per box
