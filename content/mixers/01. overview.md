# Mixers Overview

This category contains specifications and reference documentation for live sound and studio audio consoles.

## Information Stored Here
- **Console Architecture**: Digital consoles, analog mixers, rackmount mixers, broadcast surfaces
- **Channel & Bus Capacity**: Input channel counts, aux/matrix busses, DCA/VCA groups, FX engines
- **Audio Networking & Protocols**: Dante, AES50, AVB/Milan, MADI, SoundGrid, USB recording interfaces
- **Hardware Specs**: Local mic preamps, analog outputs, expansion card slots, physical fader layout
- **Processing Capabilities**: Internal DSP, sample rates, latency, plugin hosting
