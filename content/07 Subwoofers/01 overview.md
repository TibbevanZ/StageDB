# Subwoofers Overview

This category contains specifications and reference documentation for professional subwoofers.

## Information Stored Here
- **Acoustic Design**: Bass reflex, horn-loaded, bandpass, cardioid arrays, tapped horns
- **Transducers**: Single/dual 12″, 15″, 18″, 21″ low-frequency drivers, voice coil dimensions
- **Acoustic Performance**: Usable frequency range (Hz), maximum peak SPL, continuous SPL
- **Power Configuration**: Active (powered with built-in DSP/amplification) vs. passive systems
- **Rigging & Mounting**: M20 pole mounts, flyable rigging hardware, ground-stack skids
